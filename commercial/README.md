# Commercial Materials

This directory holds the buying-side artefacts for latence-trace. It
is intentionally separate from the engineering documentation under
[`../docs/operations/`](../docs/operations/).

| File | What it is | Audience |
|---|---|---|
| [`security-one-pager.md`](security-one-pager.md) | One-page security summary for procurement / TPRM. | Customer security + procurement |
| [`master-subscription-agreement.md`](master-subscription-agreement.md) | MSA template (paid commercial license). | Customer Legal |
| [`order-form-template.md`](order-form-template.md) | Order-Form template (links to MSA). | Customer Legal + Procurement |
| [`data-processing-addendum.md`](data-processing-addendum.md) | DPA template (GDPR + UK + SCC Module 2). | Customer Privacy / Legal |
| [`soc2-control-mapping.md`](soc2-control-mapping.md) | SOC 2 (TSC: Security / Availability / Confidentiality / Processing Integrity) control mapping. | Customer Audit / Compliance |
| [`trust-center.md`](trust-center.md) | Public Trust Center page (sub-processors, frameworks, status). | Anyone |
| [`audit-evidence-inventory.md`](audit-evidence-inventory.md) | Per-control evidence map. | Auditors |
| [`pilot-kit/`](pilot-kit/) | Pilot agreement, success criteria, ROI calculator, case-study and tracker templates. | AE / SE / Pilot champion |

The two complementary engineering anchors live elsewhere in the
repository:

- [`../SECURITY.md`](../SECURITY.md) -- vulnerability disclosure +
  threat model + cryptography + supply chain.
- [`../docs/operations/`](../docs/operations/) -- deployment, calibration,
  observability, licensing operations.

> All commercial templates are starting points. Provider counsel and
> Customer counsel must review and tailor them before execution.
