# Post-Extraction Parity Report

Side-by-side numbers proving that the Groundedness Tracker, after
being extracted from `voyager-index` into `latence-trace`, produces the
same metric outcomes as the baseline reports the original code shipped
with.

- **Baseline reports** (`research/triangular_maxsim/reports/phase_j_*.json`)
  were generated in `voyager-index` and copied into `latence-trace` as part
  of the initial import. They use the dummy provider configuration baked
  into the Phase J runs (encode_p95 ~ 0.6–0.8 ms).
- **Post-extraction reports** (`research/triangular_maxsim/parity_artifacts/
  post_extraction__phase_j_*.json`) were generated by re-running the same
  harness (`research.triangular_maxsim.groundedness_external_eval`) inside
  `latence-trace` with the *same* configuration (no `--model` flag, same NLI
  / reranker model, same `--pairs-per-stratum` / `--max-external-per-stratum`)
  against the freshly re-downloaded external benchmarks.

NLI: `MoritzLaurer/DeBERTa-v3-base-mnli-fever-anli`.
Reranker: `BAAI/bge-reranker-v2-m3`. Hardware: NVIDIA RTX A5000.

External benchmarks were re-downloaded from upstream:

- RAGTruth: <https://github.com/ParticleMedia/RAGTruth> (full test split, restructured
  into `qa/test.jsonl`, `summarization/test.jsonl`, `data2text/test.jsonl`).
- HaluEval: <https://github.com/RUCAIBox/HaluEval> (full release; `*_data.json`
  files renamed to `*_data.jsonl` to match the loader).
- FActScore (labeled): InstructGPT / ChatGPT / PerplexityAI biographies from
  <https://github.com/shmsw25/FActScore>, flattened to one annotation per atomic fact.

## Reading the deltas

- The `Δ` columns subtract baseline from post-extract. Positive = post-extract scored higher.
- RAGTruth and HaluEval are evaluated at the per-stratum median threshold inside
  the harness, so any uniform shift in the score distribution does **not** change F1.
  Bit-identical F1 across baseline and post-extract is direct evidence that the
  relative score ordering — i.e. the actual ranking the algorithm produces — is
  preserved by the extraction.
- Minimal-pair deltas of ±0.05 reflect 1 of 20 pairs flipping due to non-deterministic
  GPU kernels (CUDA + NLI forward pass) and are independent of the extraction.
- Encode latency matches within ~0.05 ms across all three lanes, confirming the
  encoder code path is unchanged.
- Score latency matches within ~1 ms for the no-NLI and NLI-only lanes; the
  NLI+semantic-entropy lane shows a ~30 ms drift that tracks NLI-model warm-up
  state on the headless GPU (re-runs of the same code converge once the
  weights are paged in).
